# Naval Ship Weight Estimator(Total & Series)

Windows 데스크톱 프로그램. 중량은 tonne, 치수는 m, 추진출력은 hp, 전력은 kW, 속력은 kn입니다.

## 사용

1. **Download Input File Template**: 단위·함종 목록·안내가 포함된 엑셀 양식을 저장합니다.
2. 첫 시트에 실적함 1척당 1행으로 제원과 실제 SWBS 중량을 입력합니다. 총중량은 경하중량이며 학습 시 필수 입력입니다.
3. **Input File Upload**: 전체 실적함 엑셀을 업로드하면 자동으로 계수를 학습합니다. 회귀 탭에 K, 각 회귀지수, 함종별 Dt, 기준연도, 별도의 보정계수 C, 학습 적합도를 표시합니다.
4. **Design & Weight Estimation** 탭에서 신규 함정의 함종·취역연도·길이·폭·깊이·소요마력·전력·속력을 입력하고 **Estimate Ship Weight**를 누릅니다.
5. 계열 합계, 총중량 직접 회귀값, SWBS별 중량과 분포 그래프를 확인합니다. **Export Results to Excel**로 저장합니다.
6. **③ Model Library → Save Regression Model / Load Regression Model**로 엑셀(.xlsx) 모델을 저장·불러옵니다. 기본 파일명은 Regression Model.xlsx입니다. 신규 설계함은 화면에서 직접 입력합니다. Batch Design File Upload는 삭제되었습니다.

추가 실적함이 생기면 기존 자료와 합친 전체 엑셀을 다시 업로드하세요. 신규 자료만 자동 누적하는 방식은 아닙니다. 학습·예측에 실패하면 기존 모델과 데이터는 유지됩니다.

Windows UI: 남색·청록색, 함정 벡터 도해, 입체 버튼, 영문 Times New Roman, 한글 맑은 고딕(시스템 대체 폰트 가능). 하단에 Copyright by Naval Ship Design Technology Division을 표시합니다.

학습자료와 예측자료 파일은 자동 덮어쓰기하지 않습니다. 결과 저장 시 별도 파일명을 사용하세요. Excel 수식 셀은 Excel에서 계산하고 저장한 값이 필요합니다. 데이터는 첫 시트에서만 읽습니다.

## 함종 적용

함종은 구축함, 호위함, 고속함, 상륙함, 기뢰전함, 지원함의 6개입니다. 초계함·초계정은 학습과 예측 모두 호위함으로 통합하고 각 SWBS의 호위함 Dt를 동일하게 적용합니다. 원래 입력값은 결과의 `함분류_입력` 열에 보존하고 `함분류` 열에는 실제 적용 함종을 표시합니다. 엑셀 열 제목은 `함분류` 또는 `함종`을 사용할 수 있습니다.

자료가 없는 함종의 계수는 임의 생성하지 않습니다. 호위함·초계함·초계정 중 어느 자료도 학습에 없으면 해당 함종의 예측은 거부합니다. 이전 모델에서 초계함/초계정을 별도 함종으로 학습했다면 새 버전에서 원본 엑셀로 다시 학습해야 합니다. 기존 6개 표준 함종만 사용하는 이전 모델은 불러올 수 있습니다.

## 모형

- 100: K(LBD)^α Dt
- 200: KP^α Dt exp[γ(Y−평균연도)/10]
- 300: K PE^α L^β Dt exp[γ(Y−평균연도)/10]
- 400: K Dt exp[γ(Y−평균연도)/10]
- 500: K(LBD)^α PE^β Dt exp[γ(Y−평균연도)/10]
- 600: K(LB)^α Dt
- 700: K Dt exp[γ(Y−평균연도)/10]

로그 최소제곱법. 유효 실적함 척수가 가장 많은 함종의 Dt=1입니다. 초계함·초계정은 호위함 척수에 합칩니다. 동률이면 구축함·호위함·고속함·상륙함·기뢰전함·지원함 순으로 정합니다. 기준 변경은 상대 계수의 표현을 바꾸는 것이며 동일 자료의 예측값을 바꾸지 않습니다. 학습 평균연도를 모델에 보관합니다. tonne 예측에는 Duan smearing(로그 잔차 지수의 평균)을 곱합니다. 계수 시트의 K는 보정 전 K입니다. 순항속력은 원래 식에 없으므로 사용하지 않습니다.

총중량 기본 결과는 SWBS100~700 예측 합계입니다. 실제 총중량이 있으면 별도로 K(LBD)^α P^β Dt exp[γ(Y−평균연도)/10]의 독립 총중량 회귀를 학습합니다. 이는 원래 7개 식에 추가한 기준모형이며 두 총중량은 일치하지 않을 수 있습니다. 실제 총중량 정의가 SWBS 합계와 같은지 확인하세요.

빈 값(공백 포함) 또는 잘못된 입력이 하나라도 있는 함정 행은 전체 학습에서 제외하며 행 번호와 사유를 표시합니다. 총중량도 빈 값 검사에 포함합니다. 일괄 예측은 기본 제원 8개 항목만 검사합니다. 0/음수, ?, 숫자가 아닌 값, 무한값, 잘못된 함종, 유효 범위 밖의 취역연도도 해당 행 전체를 제외하고 사유를 기록합니다. 무장 없는 함정 등 0중량이 유효한 경우 별도 모형이 필요합니다. 계수 수보다 표본 수가 커야 하고 설계행렬이 full rank여야 합니다. 이는 최소 수학적 조건이며 신뢰할 수 있는 정확도를 보장하지 않습니다. 함분류별 충분한 독립 함급이 필요합니다. 학습하지 않은 함분류 예측은 거부하고 입력의 학습범위 이탈은 표시합니다.

적합도는 학습자료 기준입니다. 독립 시험자료 또는 함급 단위 교차검증으로 실사용 정확도를 별도 확인하세요. 자동 변수 선택, 통계적 유의성 검정, 예측구간은 현재 제공하지 않습니다. 400/700은 함분류·연도만 사용하므로 장비 구성 차이를 설명하지 못합니다. 고도로 상관된 입력에서는 계수가 불안정할 수 있으며 조건수를 함께 출력합니다.

## Windows EXE 만들기

이 저장소의 GitHub Actions **Build Windows EXE**를 실행하고 완료 후 `SWBS_Regression-Windows` 아티팩트를 내려받으면 EXE가 있습니다. 이 워크플로는 저장소에 업로드되어야 실행됩니다.

또는 Windows 10/11 x64에서 Python 3.12(공식 배포판, Tcl/Tk 포함)를 설치하고 `build_windows.bat`을 실행하세요. 인터넷 연결 필요. 결과: `dist/SWBS_Regression.exe`. 실행 PC에는 Python이 필요 없습니다. 실행파일은 서명되지 않아 Windows 경고가 표시될 수 있습니다.

Linux의 PyInstaller로 Windows EXE를 만들 수 없습니다. Windows에서 빌드·GUI 실행 검증이 필요합니다.

## 개발 및 검증

기존 체크아웃을 사용하며 별도 worktree는 필요하지 않습니다.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python app.py
```

GUI에는 Tcl/Tk와 디스플레이가 필요합니다. 모델 검증은 GUI 없이 실행할 수 있습니다. 테스트 자료는 수식을 아는 합성자료이며 실제 함정 정확도를 입증하지 않습니다.

총중량 직접 회귀의 P는 소요마력(hp)입니다. 이전 저장 모델은 자동 변경되지 않습니다. 소요마력을 포함한 새 계수를 얻으려면 전체 원본 엑셀로 다시 학습하고 모델을 저장하세요.

엑셀 입력 양식은 열너비 10이며, 함종·취역연도 (년)·길이(m)·폭(m)·깊이(m)·소요마력(hp)·소요전력(kW)·순항속력(kn)·SWBS별 중량(tonne)·총중량(tonne)으로 표시합니다. 단위 없는 이전 열 이름도 읽을 수 있습니다. 제외된 행은 결과 엑셀의 `제외 행` 시트에 기록됩니다. 남은 자료가 부족하면 학습을 중단하고 기존 모델을 유지합니다.

입력 양식의 열 제목은 10pt, 가로·세로 중앙 정렬입니다. 수치가 유효한 큰 값이나 작은 값을 통계적 이상치라는 이유만으로 자동 삭제하지는 않습니다.

## ② Regression 결과 화면

사이드바는 ① Reference Fleet → ② Regression → ③ Model Library → ④ Reports 순입니다.

View All Results를 누르면 다음을 확인합니다.

- Graphs: 선택 계열의 실제·예측 산점도(1:1선)와 예측 중량 대비 오차율. 점에 마우스를 올리면 행·함종·Dt·실제/예측 중량·오차율 표시.
- Coefficients: 계열/함종별 K, C, 회귀지수, Dt, 기준 함종, 학습 척수, 기준연도.
- Ship Diagnostics: 함정 행별 적용 Dt, 실제·예측 중량, 잔차(실제−예측), 오차율((예측−실제)/실제×100).
- Fit Statistics: R², RMSE, MAPE, 계수 수, 조건수.
- Notes: 제외 및 학습 관련 안내. 모든 적합도와 그래프는 학습자료 기준입니다.

함정별 독립 Dt를 학습하는 것이 아니라 같은 함종에 같은 Dt를 적용합니다.

## 엑셀 모델 저장 형식

모델 파일에는 Model Parameters(K/C/회귀지수 등), Ship Types(함종별 Dt), Ranges(학습범위), Diagnostics(함정별 진단), 회귀계수 보기, Excluded Rows, Notes, Format 시트가 들어 있습니다. 숨긴 JSON이 아니라 표의 수치를 실제로 읽어 모델을 복원합니다. 회귀계수 보기 시트는 열람용입니다. 전체 정밀도로 저장하며 저장 전후 예측값이 유지됩니다.

계수를 직접 바꾸면 원래 학습 적합도·진단값은 자동 재계산되지 않습니다. 계수 갱신은 원본 실적함 파일의 재학습을 권장합니다. 입력 자료 엑셀과 모델 엑셀은 용도가 다릅니다. 이전 JSON 모델은 이 버전에서 불러오지 않으므로 원본 실적함 엑셀로 다시 학습한 뒤 모델 엑셀을 저장하세요.

## 순번과 함종별 결과

입력 양식은 `순번` → `함종` → 취역연도·제원·중량 순입니다. 순번은 함정의 고유 식별번호입니다. `001` 같은 문자 번호도 유지됩니다. 번호가 비어 있거나 ?가 있거나 중복이면 해당 행을 제외합니다(중복 번호의 모든 행 제외). 이전 양식처럼 순번 열 자체가 없으면 원본 순서에 따라 1부터 자동 부여합니다. 엑셀 모델 저장·불러오기와 보고서에도 순번을 보존합니다.

② Regression의 **View All Results**는 전체 결과, **View Ship Types Results**는 선택 함종의 결과를 보여줍니다. 함종별 보기는 전체 회귀모형의 계수를 유지하고 선택 함종의 그래프·진단표·적합도·해당 계수를 표시합니다. 함종별로 계수를 별도 재학습하지 않습니다. 함종별 R²는 해당 함종 실제 중량의 평균을 기준으로 계산하며, 한 척 또는 실제 중량의 변동이 없으면 정의되지 않아 —로 표시합니다. 조건수와 계수 수는 전체 모형의 값입니다.

그래프 점 옆에 순번을 표시합니다. 겹치면 **Show Ship Numbers**를 끄거나 함종별로 조회하세요. 마우스를 올리면 상세 정보, 클릭하면 해당 진단표 행으로 이동합니다. 함정별 진단표는 절대 오차율이 큰 순서이며 |오차율| 20% 이상은 붉은색으로 표시합니다. 이는 표시 기준으로, 학습에서 자동 제외하는 기준이 아닙니다. 과거 엑셀 모델에 순번이 없으면 기존 엑셀 행을 기준으로 번호를 복원하므로 직접 지정한 번호를 적용하려면 원본 자료에 순번을 넣고 다시 학습하세요.

입력 양식의 열 순서는 순번, 함종, 함유형, 취역연도(year), 길이(m), 폭(m), 깊이(m), 소요마력(hp), 소요전력(kW), 순항속력(kn), SWBS100~700(tonne), 총중량(tonne)입니다. 함유형은 기록용이며 기존 함종별 계수에는 영향을 주지 않습니다. 새 양식의 함유형은 채워야 하며 빈 값이나 ?가 있으면 해당 함정을 제외합니다. 함유형 열이 없는 이전 양식과 취역연도 (년) 표기도 계속 읽을 수 있습니다.

## 메뉴 및 회귀식 설명

사이드바는 1 / Reference Fleet, 2 / Regression, 3 / Weight Estimation, 4 / Reports입니다. Save Regression Model과 Load Regression Model은 2 / Regression에 포함됩니다.

Regression의 **Equations & Coefficient Guide** 버튼 또는 **Equations & Guide** 탭에는 SWBS100~700 식, 계열합계와 총중량 직접 회귀식, K·α·β·γ·Dt·C의 정의, 변수 단위, 연도 보정, 계수 표와 함정별 진단표의 관계 및 학습 적합도 해석이 들어 있습니다.

Weight Estimation에서 함종·길이·폭·깊이·소요마력·소요전력의 6개 필수 항목으로 예측할 수 있습니다. 취역연도는 선택 항목이며 생략하면 학습 평균 취역연도를 적용합니다(F(Y)=1). 입력 시 연도 보정을 적용합니다. 적용 연도와 입력/기본값 여부는 결과 화면과 엑셀에 남습니다. 순항속력은 현재 식에 사용하지 않으므로 신규 설계 화면에서 제거했으며 실적함 입력 양식에는 유지합니다.
