# Naval Ship Weight Estimator(Total & Series)

Windows 데스크톱 프로그램. 중량은 tonne, 치수는 m, 추진출력은 hp, 전력은 kW, 속력은 kn입니다.

## 사용

1. **Download Input File Template**: 단위·함종 목록·안내가 포함된 엑셀 양식을 저장합니다.
2. 첫 시트에 실적함 1척당 1행으로 제원과 실제 SWBS 중량을 입력합니다. 총중량은 경하중량이며 선택 입력입니다.
3. **Input File Upload**: 전체 실적함 엑셀을 업로드하면 자동으로 계수를 학습합니다. 회귀 탭에 K, 각 회귀지수, 함종별 Dt, 기준연도, 별도의 보정계수 C, 학습 적합도를 표시합니다.
4. **Design & Weight Estimation** 탭에서 신규 함정의 함종·취역연도·길이·폭·깊이·소요마력·전력·속력을 입력하고 **Estimate Ship Weight**를 누릅니다.
5. 계열 합계, 총중량 직접 회귀값, SWBS별 중량과 분포 그래프를 확인합니다. **Export Results to Excel**로 저장합니다.
6. **Save Regression Model / Load Regression Model**로 JSON 모델을 재사용합니다. **Batch Design File Upload**는 기본 제원 8개 열의 신규 설계 엑셀을 일괄 예측합니다. 화면에는 첫 함정, 결과 엑셀에는 전체 함정이 표시됩니다.

추가 실적함이 생기면 기존 자료와 합친 전체 엑셀을 다시 업로드하세요. 신규 자료만 자동 누적하는 방식은 아닙니다. 학습·예측에 실패하면 기존 모델과 데이터는 유지됩니다.

Windows UI: 남색·청록색, 함정 벡터 도해, 입체 버튼, 영문 Times New Roman, 한글 맑은 고딕(시스템 대체 폰트 가능). 하단에 Copyright by Naval Ship Design Technology Division을 표시합니다.

학습자료와 예측자료 파일은 자동 덮어쓰기하지 않습니다. 결과 저장 시 별도 파일명을 사용하세요. Excel 수식 셀은 Excel에서 계산하고 저장한 값이 필요합니다. 데이터는 첫 시트에서만 읽습니다.

## 함종 적용

함종은 구축함, 호위함, 고속함, 상륙함, 기뢰전함, 지원함의 6개입니다. 초계함·초계정은 학습과 예측 모두 호위함으로 통합하고 각 SWBS의 호위함 Dt를 동일하게 적용합니다. 원래 입력값은 결과의 `함분류_입력` 열에 보존하고 `함분류` 열에는 실제 적용 함종을 표시합니다. 엑셀 열 제목은 `함분류` 또는 `함종`을 사용할 수 있습니다.

자료가 없는 함종의 계수는 임의 생성하지 않습니다. 호위함·초계함·초계정 중 어느 자료도 학습에 없으면 해당 함종의 예측은 거부합니다. 이전 모델에서 초계함/초계정을 별도 함종으로 학습했다면 새 버전에서 원본 엑셀로 다시 학습해야 합니다. 기존 6개 표준 함종만 사용하는 이전 모델은 불러올 수 있습니다.

## 모형

- 100: K(LBD)^α Dt
- 200: KP^α Dt exp[γ(Y−평균연도)/10]
- 300: K PE^α L^β Dt exp[γ(Y−평균연도)/10]
- 400: K Dt exp[γ(Y−평균연도)/10]
- 500: K(LBD)^α PE^β Dt exp[γ(Y−평균연도)/10]
- 600: K(LB)^α Dt
- 700: K Dt exp[γ(Y−평균연도)/10]

로그 최소제곱법. 기준 함분류(문자 정렬 첫 항목)의 Dt=1. 학습 평균연도를 모델에 보관합니다. tonne 예측에는 Duan smearing(로그 잔차 지수의 평균)을 곱합니다. 계수 시트의 K는 보정 전 K입니다. 순항속력은 원래 식에 없으므로 사용하지 않습니다.

총중량 기본 결과는 SWBS100~700 예측 합계입니다. 실제 총중량이 있으면 별도로 K(LBD)^α P^β Dt exp[γ(Y−평균연도)/10]의 독립 총중량 회귀를 학습합니다. 이는 원래 7개 식에 추가한 기준모형이며 두 총중량은 일치하지 않을 수 있습니다. 실제 총중량 정의가 SWBS 합계와 같은지 확인하세요.

0/음수/결측 중량은 임의 보정하지 않고 거부합니다. 무장 없는 함정 등 0중량이 유효한 경우 별도 모형이 필요합니다. 계수 수보다 표본 수가 커야 하고 설계행렬이 full rank여야 합니다. 이는 최소 수학적 조건이며 신뢰할 수 있는 정확도를 보장하지 않습니다. 함분류별 충분한 독립 함급이 필요합니다. 학습하지 않은 함분류 예측은 거부하고 입력의 학습범위 이탈은 표시합니다.

적합도는 학습자료 기준입니다. 독립 시험자료 또는 함급 단위 교차검증으로 실사용 정확도를 별도 확인하세요. 자동 변수 선택, 통계적 유의성 검정, 예측구간은 현재 제공하지 않습니다. 400/700은 함분류·연도만 사용하므로 장비 구성 차이를 설명하지 못합니다. 고도로 상관된 입력에서는 계수가 불안정할 수 있으며 조건수를 함께 출력합니다.

## Windows EXE 만들기

이 저장소의 GitHub Actions **Build Windows EXE**를 실행하고 완료 후 `SWBS_Regression-Windows` 아티팩트를 내려받으면 EXE가 있습니다. 이 워크플로는 저장소에 업로드되어야 실행됩니다.

또는 Windows 10/11 x64에서 Python 3.12(공식 배포판, Tcl/Tk 포함)를 설치하고 `build_windows.bat`을 실행하세요. 인터넷 연결 필요. 결과: `dist/SWBS_Regression.exe`. 실행 PC에는 Python이 필요 없습니다. 실행파일은 서명되지 않아 Windows 경고가 표시될 수 있습니다.

Linux의 PyInstaller로 Windows EXE를 만들 수 없습니다. Windows에서 빌드·GUI 실행 검증이 필요합니다.

## 개발 및 검증

기존 체크아웃을 사용하며 별도 worktree는 필요하지 않습니다.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python app.py
```

GUI에는 Tcl/Tk와 디스플레이가 필요합니다. 모델 검증은 GUI 없이 실행할 수 있습니다. 테스트 자료는 수식을 아는 합성자료이며 실제 함정 정확도를 입증하지 않습니다.

총중량 직접 회귀의 P는 소요마력(hp)입니다. 이전 저장 모델은 자동 변경되지 않습니다. 소요마력을 포함한 새 계수를 얻으려면 전체 원본 엑셀로 다시 학습하고 모델을 저장하세요.
