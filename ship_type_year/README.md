# Naval Ship Weight Estimator — 세 후보식 자동 선택

실적함 엑셀을 업로드하면 계열마다 세 수식을 학습하고 전체 실적함 MAPE가 가장 작은 식과 계수를 선택합니다. 추가 입력 열은 없습니다. 이전 프로그램은 이전 GitHub 릴리스에 보존됩니다.

| 계열 | 기존 항 | 추천 항 | 추가 후보 |
|---|---|---|---|
| 100 | K(LBD/V0)^αt | K(LB)^a D^b | KL^a B^b D^c |
| 200 | KP^a | KP^a L^b | k0+k1P |
| 300 | KPE^a L^b | KPE^a(LB)^b | k0+k1PE+k2L |
| 400 | K | K(LB)^a | KPE^a |
| 500 | K(LBD)^a PE^b | K(LB)^a PE^b | k0+k1LBD+k2PE |
| 600 | K(LB)^a | K(LBD)^a | k0+k1LB |
| 경하중량, 700 제외 | K(LBD)^a P^b | K(LB)^a D^b P^c | k0+k1LBD+k2P+k3PE |

각 항 전체에 Dt × exp[γt(Y−Ȳt)/10] × C를 적용합니다. K와 C는 별도입니다. 기존 100계열만 함종별 크기 지수이며 나머지 크기·출력 지수와 가산계수는 함종 공통입니다. Dt·γt는 함종별이고 기준 함종 Dt=1입니다.

거듭제곱식은 로그 최소제곱, 덧셈식은 양수 계수 제약을 둔 로그 잔차 비선형 최소제곱으로 추정합니다. 덧셈식은 제원을 중앙값으로 정규화해 최적화한 뒤 원래 단위 계수로 저장합니다. 해는 수치 최적화 결과이며 전역 최적 보장은 없습니다. 모든 후보의 기준 γt를 먼저 추정하고 0%,1%,…,200%로 적용해 각 비율에서 나머지 계수와 C를 다시 추정합니다. 비율 선택은 Train MAPE, RMSE, 작은 비율 순입니다. 수식 선택은 Train MAPE, RMSE, 기존→추천→추가 식 순이며 점수 동률은 소수점 8자리 기준입니다.

한 후보를 식별할 수 없거나 수렴하지 않아도 다른 후보는 계속 계산합니다. 연도 효과만 식별 불가하면 해당 후보는 0%만 계산하고 사유를 표시합니다. 세 후보 모두 실패하면 해당 계열은 오류를 안내합니다. 직접 경하중량만 실패하면 계열 합계는 유지합니다. 진행 화면에 계열·후보·연도 효과와 움직이는 돋보기를 표시합니다.

업로드 완료 후 SWBS100 그래프부터 표시합니다. Equations & Guide에는 선택한 함종의 최종 선택 수식과 변수·계수 설명만 표시하며 설계 제원도 숫자로 대입할 수 있습니다. Formula Comparison 탭과 비교 엑셀 시트는 제거했습니다. Save Regression Model과 결과 엑셀에는 최종 선택 계수와 선택 모델의 연도 탐색 기록을 저장합니다. 가산계수는 Model Parameters의 Add_constant·Add_변수 열, 회귀계수 보기의 가산계수 열에 저장됩니다. 덧셈식의 Model Parameters K=1 및 지수=0은 공통 저장 형식용이며 사용하지 않습니다. 실제 예측은 Kind=additive의 Add_계수와 Dt·γt·C를 사용합니다.

Weight Estimation의 함종 선택에서 초계정을 제거했습니다. 입력 실적 엑셀의 초계정·초계함을 호위함으로 통합하는 기존 규칙은 유지합니다. 빈 값·오류 행 제외 규칙과 입력 양식을 유지합니다. 함유형과 순항속력은 기록용입니다.

700계열은 추정하지 않습니다. 합계는 100~600이고 직접 경하중량 목표는 원래 총중량−실적 SWBS700입니다. 기존 전체 실적함을 다시 업로드해 학습하세요. 표시 성능은 학습자료 적합도이며 교차 검증 성능이 아닙니다.

개발: 이 폴더에서 `python -m pip install -r requirements.txt`, `python -m unittest discover -s tests -v`. GUI 검사는 Windows 데스크톱 또는 DISPLAY가 필요합니다. GitHub Actions는 Windows GUI·동봉 수식 렌더러·EXE 실행을 검사합니다.

연도 효과 탐색은 0~200%, 1% 간격의 201개 후보입니다. 각 계열의 세 후보식 모두에 적용합니다. 100%는 기본 γt 그대로, 200%는 그 두 배입니다. Analysis Target 옆에 선택 계열의 영문 이름을 표시합니다.
