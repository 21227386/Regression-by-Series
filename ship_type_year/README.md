# Naval Ship Weight Estimator — 수식 자동 비교

실적함 엑셀을 업로드하면 기존 식과 추천 식을 각각 학습하고 계열별 최적 수식을 선택합니다. 추가 입력 열은 필요 없습니다. 기존 버전은 이전 GitHub 릴리스에 보존됩니다.

| 계열 | 기존 크기·출력 항 | 추천 크기·출력 항 |
|---|---|---|
| 100 | (LBD/V0)^αt, 함종별 크기 지수 | (LB)^a D^b, 공통 지수 |
| 200 | P^a | P^a L^b |
| 300 | PE^a L^b | PE^a (LB)^b |
| 400 | 없음 | (LB)^a |
| 500 | (LBD)^a PE^b | (LB)^a PE^b |
| 600 | (LB)^a | (LBD)^a |
| 경하중량 직접회귀, 700 제외 | (LBD)^a P^b | (LB)^a D^b P^c |

모든 식에 K × Dt × exp[γt(Y−Ȳt)/10] × C를 적용합니다. 계열·후보별로 기준 γt를 먼저 추정하고 0%,1%,…,100%로 고정해 각 후보에서 다른 계수와 C를 재추정합니다. 비율 후보는 Train MAPE 최소, 동률이면 RMSE, 그다음 작은 비율 순입니다. 식 후보는 Train MAPE 최소, 동률이면 RMSE, 그다음 기존 식을 우선합니다. 점수 동률은 소수점 8자리 반올림 기준입니다. 최대 절대오차율·R²도 비교표에 표시하지만 선택 기준은 아닙니다. 교차 검증은 수행하지 않습니다.

2 / Regression의 Formula Comparison 탭이 학습 직후 열립니다. 계열당 기존·추천 두 후보의 수식, 선택 여부, MAPE, RMSE, R², 최대 절대오차율, 연도 효과, 계산 불가 사유를 표시합니다. 신규 함정 예측·그래프·진단표는 선택된 모델을 사용합니다. Equations & Guide 상단에 최종 선택 식의 계수가 숫자로 표시되고 설계 제원도 대입할 수 있습니다. 하단 이미지는 기존 식 참고용입니다.

한 식을 계산할 수 없어도 다른 후보는 계산합니다. 연도 효과만 식별 불가하면 해당 후보는 0%만 계산하고 이유를 표시합니다. 두 후보 모두 실패하면 해당 계열은 학습 오류를 안내합니다. 경하중량 직접회귀만 실패하면 계열 합계는 유지하고 안내합니다. 해석 중에는 움직이는 돋보기와 계열·후보별 진행률을 표시합니다.

Save Regression Model 및 결과 엑셀의 Formula Comparison 시트에 두 후보 비교를, Formula Year Search에 두 식의 연도 탐색 전체를 저장합니다. Model Parameters와 회귀계수 보기에는 실제 선택된 모델의 설명변수·계수를 저장합니다.

700계열은 추정하지 않습니다. 합산 중량은 100~600 합계이고 직접 회귀 목표는 입력한 원래 총 경하중량−실적 SWBS700입니다. 기존 입력 양식과 빈 값·오류 행 제외 규칙을 유지합니다. 함유형과 순항속력은 기록용이며 현재 두 후보식의 설명변수로 쓰지 않습니다. 전체 실적함을 다시 업로드해 학습하세요.

개발: 이 폴더에서 `python -m pip install -r requirements.txt`, `python -m unittest discover -s tests -v`를 실행합니다. GUI 검사는 Windows 데스크톱 또는 DISPLAY가 필요합니다. Windows EXE는 GitHub Actions에서 PyInstaller로 빌드하며 GUI·동봉 수식 렌더러·실행 검사를 수행합니다.
