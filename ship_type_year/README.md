# Naval Ship Weight Estimator — 세 후보식 자동 선택

실적함 엑셀을 업로드하면 계열마다 세 수식을 학습하고 WAPE 허용기준을 충족하는 후보 중 전체 실적함 MAPE가 가장 작은 식과 계수를 선택합니다. 추가 입력 열은 없습니다. 이전 프로그램은 이전 GitHub 릴리스에 보존됩니다.

| 계열 | 기존 항 | 추천 항 | 추가 후보 |
|---|---|---|---|
| 100 | K(LBD/V0)^αt | K(LB)^a D^b | KL^a B^b D^c |
| 200 | KP^a | KP^a L^b | k0+k1P |
| 300 | KPE^a L^b | KPE^a(LB)^b | k0+k1PE+k2L |
| 400 | K | K(LB)^a | KPE^a |
| 500 | K(LBD)^a PE^b | K(LB)^a PE^b | k0+k1LBD+k2PE |
| 600 | K(LB)^a | K(LBD)^a | k0+k1LB |
| 경하중량, 700 제외 | K(LBD)^a P^b | K(LB)^a D^b P^c | k0+k1LBD+k2P+k3PE |

각 항 전체에 Dt × exp[γt(Y−Ȳt)/10] × C를 적용합니다. K와 C는 별도입니다. 기존 100계열만 함종별 크기 지수이며 나머지 크기·출력 지수와 가산계수는 함종 공통입니다. Dt·γt는 함종별이고 기준 함종 Dt=1입니다.

거듭제곱식은 로그 최소제곱, 덧셈식은 양수 계수 제약을 둔 로그 잔차 비선형 최소제곱으로 추정합니다. 덧셈식은 제원을 중앙값으로 정규화해 최적화한 뒤 원래 단위 계수로 저장합니다. 해는 수치 최적화 결과이며 전역 최적 보장은 없습니다. 모든 후보의 기준 γt를 먼저 추정하고 0%,1%,…,200%로 적용해 각 비율에서 나머지 계수와 C를 다시 추정합니다. 비율 선택은 Train MAPE, RMSE, 작은 비율 순입니다. 수식 선택은 Train MAPE, RMSE, 기존→추천→추가 식 순이며 점수 동률은 소수점 8자리 기준입니다.

한 후보를 식별할 수 없거나 수렴하지 않아도 다른 후보는 계속 계산합니다. 연도 효과만 식별 불가하면 해당 후보는 0%만 계산하고 사유를 표시합니다. 세 후보 모두 실패하면 해당 계열은 오류를 안내합니다. 직접 경하중량만 실패하면 계열 합계는 유지합니다. 진행 화면에 계열·후보·연도 효과와 움직이는 돋보기를 표시합니다.

업로드 완료 후 SWBS100 그래프부터 표시합니다. Equations & Guide에는 선택한 함종의 최종 선택 수식과 변수·계수 설명만 표시하며 설계 제원도 숫자로 대입할 수 있습니다. Formula Comparison 탭과 비교 엑셀 시트는 제거했습니다. Save Regression Model은 최종 결과 네 시트만 저장합니다(아래 설명 참조). 개발 API의 기존 모델 보관 파일에는 연도 탐색 기록과 Model Parameters 등의 복원용 데이터가 저장됩니다. 이 보관 형식에서 덧셈식의 K=1 및 지수=0은 사용하지 않는 자리표시자이고 실제 예측은 Kind=additive의 Add_계수와 Dt·γt·C를 사용합니다.

Weight Estimation의 함종 선택에서 초계정을 제거했습니다. 입력 실적 엑셀의 초계정은 호위함으로 통합하며 초계함은 별도로 학습합니다. 빈 값·오류 행 제외 규칙과 입력 양식을 유지합니다. 함유형과 순항속력은 기록용입니다.

700계열은 추정하지 않습니다. 합계는 100~600이고 직접 경하중량 목표는 원래 총중량−실적 SWBS700입니다. 기존 전체 실적함을 다시 업로드해 학습하세요. 표시 성능은 학습자료 적합도이며 교차 검증 성능이 아닙니다.

개발: 이 폴더에서 `python -m pip install -r requirements.txt`, `python -m unittest discover -s tests -v`. GUI 검사는 Windows 데스크톱 또는 DISPLAY가 필요합니다. GitHub Actions는 Windows GUI·동봉 수식 렌더러·EXE 실행을 검사합니다.

연도 효과 탐색은 0~200%, 1% 간격의 201개 후보입니다. 각 계열의 세 후보식 모두에 적용합니다. 100%는 기본 γt 그대로, 200%는 그 두 배입니다. Analysis Target 옆에 선택 계열의 영문 이름을 표시합니다.


## WAPE 기준을 둔 후보 선택

계수 추정 절차(로그 최소제곱 / 양수 덧셈식 비선형 로그 최소제곱)는 유지합니다. 계수 자체의 직접 MAPE·WAPE 제약 최적화가 아니라, 계산된 수식×연도 효과 후보 선택에 WAPE 제약을 적용합니다.

WAPE = 100 × Σ|실제−예측| / Σ실제입니다. 전체 유효 실적함으로 계열·직접 경하중량별 독립 평가합니다. 초기 기준은 10%이며 GUI에서 바꿀 수 있습니다. 한 계열의 세 식과 모든 0~200% 연도 후보 중 하나라도 기준을 만족하면 완화하지 않습니다. 아무 후보도 만족하지 않으면 해당 계열만 1%p 단위로 늘려 처음 후보가 생기는 기준에서 멈춥니다. 그 기준을 만족하는 모든 후보 중 MAPE 최소, RMSE, 기존→추천→추가 식 우선순으로 선택합니다. 같은 식 안의 동률은 더 작은 연도 비율을 우선합니다. 계산된 WAPE로 최소 완화 횟수를 구하므로 완화 때마다 회귀를 반복할 필요는 없습니다. 수치 비교 허용오차는 1e-9 %p입니다.

자동 완화에 별도 상한은 없습니다. 완화 여부·초기 기준·실제 적용 기준·실제 WAPE를 Year Effect Search, Fit Statistics, 최종식 설명과 결과 엑셀의 적합도 요약에 표시합니다. 개발 API의 모델 보관 형식에는 Model Parameters 및 Year Selection에도 저장됩니다. 모든 후보의 수치 계산이 실패하면 기준을 늘려 해결한 것처럼 처리하지 않고 오류를 안내합니다. 수치 문제로 독립 경하중량 회귀만 불가능한 경우 기존처럼 경고와 계열 합계를 유지합니다.

입력 템플릿은 ‘데이터’ 시트 하나만 생성합니다. 함종 안내·단위·사용 안내 시트는 삭제했습니다. 열 제목의 단위·너비 10·10pt 중앙 정렬·셀 설명·함종 드롭다운은 유지합니다.


## 초계함 전용 Dt와 자료 증가 시 독립 계수

초계함은 별도 함종으로 저장·조회·예측합니다. 다른 함종으로 공통 크기·출력 추세와 기준 계수를 먼저 학습한 뒤, 초계함 전용 Dt를 각 계열 및 직접 경하중량에서 추정합니다. Dt는 C까지 포함한 최종 중량에 대해 보정하므로 한 척이면 그 실적 중량을 수치 정밀도 내에서 재현합니다. 초계함 한 척의 평균연도는 그 척의 연도이고 γt는 0입니다. 따라서 초계함 한 척이 다른 함종의 연도 효과를 끄지 않습니다.

기존 100계열 식에서 초계함의 LBD가 서로 다른 자료가 2척 이상이면 초계함 규모 지수를 따로 추정합니다. 한 척 또는 같은 LBD뿐이면 호위함 규모 지수를 공유하고, 호위함이 없으면 비초계함 기준 함종의 지수를 공유합니다. 두 척만으로 규모와 연도 효과를 동시에 추정하지 않습니다. 3척 이상이고 [상수, log(LBD/V0), 중심연도]가 독립일 때만 둘 다 추정하며, 그렇지 않으면 규모 지수를 우선하고 γt=0을 유지합니다. 크기가 모두 같으면 규모는 공유하고 연도 자료가 있으면 γt를 추정합니다. 나머지 후보식은 본래 함종 공통 크기·출력 계수 구조를 유지하며, 서로 다른 연도의 초계함이 2척 이상이면 초계함 γt를 별도로 추정합니다.

각 0~200% 연도 후보마다 초계함 Dt와 추정 가능한 규모 지수를 다시 보정합니다. WAPE 10% 및 계열별 자동 완화 규칙은 동일합니다. 공통 추세는 다른 함종 자료로 계속 학습하며, 초계함 데이터 증가가 곧 초계함만의 모든 변수를 자유롭게 추정한다는 뜻은 아닙니다. 기준 함종은 비초계함 중 유효 척수가 가장 많은 함종으로 유지합니다. 초계함밖에 없거나 공유 추세를 식별할 비초계함 자료가 부족하면 오류를 안내합니다.

공유·독립 여부와 자료 수는 최종 수식 설명과 결과 엑셀의 최종 수식 시트에 표시합니다. 개발 API의 모델 보관 형식에는 Model Parameters의 PatrolInfo로 저장되며 SizeAlpha·Gamma·Dt를 로드해 같은 예측을 재현할 수 있습니다. 한두 척에 맞춘 포화 적합은 신규 설계 정확도의 검증이 아닙니다. 전체 실적함을 다시 업로드해야 새 구분과 자료 증가가 적용됩니다.


화면 부제와 창 제목은 Commissioning Year Adjustment by Ship Type입니다. 그래프 점·순번 및 함정별 진단표는 절대 오차율이 10%를 초과할 때 붉게 표시하며 정확히 ±10%는 일반 색상입니다. Equations & Guide의 수식 제목은 계열 / 함종만 표시합니다. Weight Estimation의 신규 설계 함종 메뉴에서만 기뢰전함을 제외하고, 실적함 입력·학습·회귀 결과 조회는 그대로 지원합니다.


상단 부제는 Total & Series / Commissioning Year Adjustment by Ship Type입니다. 한글 설명은 11pt 굵게 표시하고 헤더 높이를 실제 글자 높이에 맞춥니다. 회귀분석은 spawn 방식의 별도 프로세스에서 수행하여 Tk 화면과 Python 실행 잠금을 공유하지 않습니다. 진행 메시지는 50ms 단위로 합치고 UI에서 한 번에 최대 16개만 읽습니다. 돋보기는 40ms 간격으로 기존 도형 위치를 변경하며 계산 시작부터 완료·오류까지 반복합니다. Windows EXE의 freeze_support 및 별도 프로세스 전체 회귀 스모크 검사를 CI에서 수행합니다.


## Save Regression Model의 간소화된 결과 엑셀

이 버튼은 이제 모델 복원용 내부 파일 대신 Regression Results의 Graphs 및 Equations & Guide 결과를 확인하는 엑셀을 저장합니다. 기본 파일명은 Regression Results.xlsx입니다. 시트는 중량 비교, 최종 수식, 계수, 적합도 요약 네 개만 생성합니다. 후보 탐색 기록·학습 범위·형식 메타데이터 등 내부 시트는 포함하지 않습니다. 중량 비교에는 유효 실적함 전체의 각 계열 및 700 제외 직접 경하중량 실측·추정·잔차·오차율을 저장하고 함종 열 필터로 조회합니다. 현재 GUI의 선택 계열·함종 필터나 신규 설계 입력과 관계없이 전체 학습 결과를 내보냅니다. 적합도는 전체 및 함종별로 같은 최종 모델의 진단값을 사용합니다. WAPE 적용 기준은 전체 학습자료 기준임을 열 제목에 표시합니다.

최종 수식은 입력 변수 L·B·D·P·PE·Y만 남기고 실제 선택 계수를 숫자로 대입한 텍스트입니다. 수식과 별도로 계수 시트의 값 열에 반올림하지 않은 숫자를 저장합니다. αt·Dt·적용 γt·C·V0·평균연도·연도 비율과 덧셈식 가산계수를 모두 포함하며, 덧셈식에 사용하지 않는 K나 0 자리표시자는 내보내지 않습니다. 합산 중량은 별도 계수가 아닌 W100~W600의 합으로 표시합니다. 순번은 문자열로 유지합니다.

이 결과용 파일은 Load Regression Model로 복원하는 파일 형식이 아닙니다. 현재 GUI에는 Load 버튼이 없으며 원본 실적함을 다시 업로드하면 재학습합니다. 개발 API save_model_excel/load_model_excel의 기존 모델 보관 형식과 Reports 버튼의 출력은 호환성을 위해 별도로 유지합니다.
