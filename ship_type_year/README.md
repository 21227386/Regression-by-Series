# SWBS Regression — 함종별 연도 보정

기존 공통 연도 보정 버전과 without year를 변경하지 않는 별도 버전입니다. 새 회귀식:

Ft(Y) = exp[γt (Y−함종평균연도t)/10]

각 SWBS 계열 및 총 경하중량 모형에서 함종별 평균 취역연도와 γt를 따로 추정합니다. 크기·출력의 회귀지수는 해당 계열 전체에서 공통이며, 함종 절편(Dt)과 연도 기울기는 함종마다 다릅니다. 공통 γ를 그대로 재사용하거나 평균연도만 바꾸는 방식이 아닙니다.

SWBS200·300·400·500·700과 총중량 직접 회귀에 적용하며, 기존 SWBS100·600에는 연도 항을 추가하지 않습니다. 계열 합산 중량과 전체 경하중량 직접 회귀값을 모두 표시합니다. C는 기존처럼 모형별 공통 역변환 보정계수이며 K와 분리합니다.

## 사용

전체 실적함 엑셀을 다시 업로드해 학습하세요. 이전 모델의 계수나 엑셀 모델을 혼용하지 않도록 파일 형식을 구분합니다. 입력 양식, 순번, 함종·함유형, 오류 행 제외, 기준 함종 자동 선택, 함종별 결과 조회는 기존과 같습니다. 초계함·초계정은 호위함으로 합쳐 평균연도와 γt를 계산합니다.

설계함의 취역 예상연도를 넣으면 선택한 함종의 γt와 평균연도로 보정합니다. 미입력 시 선택한 함종의 평균연도를 적용하여 Ft=1로 예측합니다. 계수 표에 γt와 함종평균연도를 표시하고 진단표·모델 엑셀에는 적용 Ft(Y), 취역연도도 보존합니다.

Dt는 각 함종의 자체 평균연도에서의 상대 수준입니다. 같은 달력 연도에서 함종을 비교할 때는 Dt와 Ft(Y)를 함께 적용해야 합니다.

## 자료 조건

연도 효과를 사용하는 모형에서는 각 함종에 서로 다른 취역연도가 최소 2개 필요합니다. 전체 표본 수는 전체 계수 수보다 커야 하며 설계행렬이 full rank여야 합니다. 부족하면 학습 오류를 표시하며 임의의 공통 γ나 γ=0으로 대체하지 않습니다. 이 조건은 수학적 최소 조건이며 예측 정확도를 보장하지 않습니다. 학습 적합도와 독립 함급 검증 성능을 구분하세요.

## 개발

이 폴더에서 requirements.txt를 설치하고 `python -m unittest discover -s tests -v`를 실행합니다. Windows 빌드: `python -m PyInstaller --onefile --windowed --name SWBS_Regression --add-data "assets;assets" app.py`. 수식 이미지는 assets/equations에 포함되어 있습니다.

## 700계열 제외 버전

700계열 회귀모형·예측·그래프·계수·진단은 생성하지 않습니다. 계열 합계는 SWBS100~600만 합산합니다. 경하중량 직접 회귀의 학습 목표는 **입력 총 경하중량−입력 실적 SWBS700**이며 한 번만 공제합니다. 추정 결과는 두 방식 모두 700계열 제외 중량으로 표시합니다.

입력 양식의 SWBS700은 공제용 실제 중량으로 유지하며 0을 허용합니다. 총중량에는 SWBS700 포함 원래 경하중량을 입력하세요. 이미 공제한 중량을 넣으면 이중 공제가 되므로 사용하지 마세요. 총중량−SWBS700이 0 이하인 행은 제외합니다. 기존 700 포함 모델과 혼용하지 않도록 모델 형식을 변경했습니다. 전체 실적함 엑셀로 다시 학습하세요.

## 연도 효과 100%~10% 자동 선택

Input File Upload 후 200·300·400·500 및 700 제외 경하중량 직접 회귀에서 10개 후보를 비교합니다. 각 모형의 원래 함종별 γt를 q(1.0~0.1)배로 고정하고, 나머지 K·크기/출력 지수·Dt와 잔차 기반 C를 다시 추정합니다. 이는 γt만 고정 비율로 변경하고 나머지를 그대로 두는 방식이나 Ridge 벌점 방식과 다릅니다.

기본 검증은 함종 내 척별 최대 5분할입니다. 함유형은 DDG/FFG 분류 코드이므로 함급으로 사용하지 않습니다. 함급별 검증을 원하면 입력 엑셀에 별도 함급 열을 제공하고 업로드 전에 검증 방식을 변경하세요. 동일 함급 자매함이 척별 분할 양쪽에 있으면 신규 함급에 대한 성능을 낙관적으로 볼 수 있습니다.

각 분할의 기본 γt·평균연도·다른 계수·C는 학습 부분만 이용합니다. 모든 후보를 같은 유효 검증 분할로 비교하고 검증 자료를 합쳐 계산한 MAPE를 최소화합니다. 동률은 RMSE, 수치적으로 같은 점수는 더 큰 비율을 우선합니다. 비율은 모형별 하나를 선택하며 각 함종의 원래 γt에 공통 적용합니다. 선택 후 전체 데이터로 다시 추정한 계수를 최종 사용합니다.

3척 미만 함종은 척별 검증에서 학습 부분에만 남깁니다. 자료 부족·연도 다양성 부족·rank 오류 등으로 실패한 분할은 제외하고 검증 척수·분할 수·이유를 표시합니다. 유효 검증이 2회 미만 또는 3척 미만이면 검증 불가로 100%를 유지합니다. 부분 검증의 선택 비율은 검증되지 않은 함종에도 적용되므로 범위를 확인하세요. 검증 점수는 비율 선택에 사용한 점수이며 최종 독립 시험 성능이 아닙니다.

Year Effect Search 탭에서 100%~10%의 학습/검증 MAPE·RMSE, 선택 비율, 검증 척수, 그래프를 봅니다. Fit Statistics에서는 계열별 선택 비율과 검증 점수를 함께 봅니다. Coefficients의 기본 γt와 적용 γt는 구분되며 예측에는 이미 축소된 적용 γt를 한 번만 사용합니다. 엑셀 모델과 결과 파일의 Year Search, Year Selection, Validation Predictions 시트에 후보 비교 및 선택 후보의 검증 예측을 저장합니다. 100·600에는 연도 항이 없어 이 탐색을 적용하지 않습니다. 700은 추정하지 않습니다.

## 100계열 함종별 규모 효과

100계열만 W100 = K (LBD/V0)^αt Dt C로 변경했습니다. αt는 함종별 규모 회귀지수이며 V0는 전체 유효 학습 LBD의 기하평균(m³)입니다. V0는 저장한 값을 신규 예측에도 그대로 사용합니다. 각 함종에 서로 다른 LBD가 최소 2개 필요하며 전체 표본 수가 전체 계수 수(함종 수의 2배)보다 커야 합니다. 이 조건은 추정의 최소 수학적 조건이며 정확도를 보장하지 않습니다.

Coefficients와 엑셀의 LBD 지수는 100계열에서 해당 함종의 αt를 나타냅니다. 기준LBD 열도 함께 표시합니다. K·Dt는 공통 기준 규모 V0에서의 수준이며, 서로 다른 αt 때문에 V0가 아닌 규모에서는 Dt만으로 함종 간 중량 비율을 비교할 수 없습니다. Ship Types 시트에 SizeAlpha, Model Parameters에 SizeByType·VolumeReference를 저장하고 예측 시 사용합니다. 다른 계열의 크기·출력 지수와 함종별 연도 보정·연도 효과 자동 탐색·700 제외 방식은 유지합니다. 100계열에 연도 항을 추가하지 않았습니다.

100계열의 함종별 규모 지수는 전체 유효 실적함으로 학습한 값이며, Year Effect Search의 교차검증은 연도 효과 선택용입니다. 새 함급에서의 규모 모형 정확도 개선은 별도 검증자료로 확인하세요. 함종별 자료가 적으면 αt가 불안정할 수 있습니다. 기존 저장 모델을 자동 변환하지 않으므로 전체 실적함을 다시 업로드해 학습하세요.
