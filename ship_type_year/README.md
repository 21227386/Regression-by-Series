# Naval Ship Weight Estimator — 실적함 적합 모드

유효 실적함 전체의 Train MAPE가 가장 작도록 연도 효과를 선택하는 Windows GUI 프로그램입니다. 검증용 함정을 분리하지 않습니다. 기존 버전은 GitHub의 이전 릴리스에 보존되어 있습니다.

## 사용

1. Reference Fleet에서 입력 양식을 저장하고 전체 실적함 엑셀을 업로드합니다.
2. 연도 효과 0%, 1%, …, 100%의 101개 후보를 계열별로 계산합니다.
3. 각 후보에서 함종별 기본 γt에 비율을 적용해 고정한 뒤 K·규모/출력 지수·Dt와 역변환 보정계수 C를 전체 자료로 다시 추정합니다.
4. Train MAPE 최소 후보를 선택합니다. 동률이면 Train RMSE, 수치적으로 같은 점수이면 더 작은 비율을 우선합니다.
5. Year Effect Search에서 전체 실적함의 MAPE·RMSE와 선택 결과를 보고, Save Regression Model로 모델 엑셀을 저장합니다.
6. Weight Estimation에서 신규 함정 제원을 입력하고 Reports에서 결과를 저장합니다.

왼쪽의 함급별·함종 내 척별 검증 메뉴와 CV 지표는 제거했습니다. 100·600계열에는 연도 항이 없어서 비율 탐색을 적용하지 않습니다. 검색 범위 밖 임시값이나 검증 불가 기본값을 사용하지 않으며, 계산 가능한 후보가 없으면 오류를 안내합니다. 여기서 선택하는 것은 입력 실적함 적합도이며 신규 함급 검증 성능을 의미하지 않습니다.

## 회귀식과 함종별 계수

100계열: W100 = K (LBD/V0)^αt Dt C. αt는 함종별 규모 지수, V0는 전체 학습 LBD의 기하평균(m³)입니다. 각 함종의 서로 다른 LBD가 최소 2개 필요하고 전체 표본이 계수 수보다 많아야 합니다. K·Dt는 공통 기준 규모 V0에서 해석합니다.

200·300·400·500 및 700 제외 경하중량 직접 회귀는 Ft(Y)=exp[γt(Y−함종평균연도t)/10]을 사용합니다. 계열별 선택 비율은 해당 모형의 함종별 기본 γt에 공통 적용합니다. 다른 계수는 후보마다 다시 추정합니다. 계수 표의 적용 γt에는 선택 비율이 이미 반영되어 있으므로 예측에서 다시 곱하지 않습니다.

설계함의 취역 예상연도를 생략하면 선택 함종의 학습 평균연도를 적용합니다. 600계열은 기존 면적 지표 기반 식입니다. C는 K와 분리하여 적용합니다. 기준 함종은 유효 척수가 가장 많은 함종이고 Dt=1이며 초계함·초계정은 호위함으로 통합합니다.

## 700계열 제외

700계열은 추정하지 않습니다. 합산 중량은 SWBS100~600만 합합니다. 경하중량 직접 회귀는 입력한 원래 경하중량에서 실적 SWBS700을 한 번 뺀 값을 학습합니다. SWBS700 열은 공제용으로 필요하며 0을 허용합니다. 이미 공제한 총중량을 입력하지 마세요. 화면과 결과 엑셀 모두 700계열 제외 중량으로 표시합니다.

## 입력과 결과

양식 순서: 순번·함종·함유형·취역연도(year)·길이(m)·폭(m)·깊이(m)·소요마력(hp)·소요전력(kW)·순항속력(kn)·SWBS100~700(tonne)·총중량(tonne). 함유형은 DDG/FFG 같은 기록용 분류이며 회귀 설명변수로 사용하지 않습니다. 순항속력도 현재 식에는 사용하지 않습니다. 빈 값·?·오류가 있는 함정 행은 제외합니다.

그래프와 진단표에 순번을 보존하며 함종별로 조회할 수 있습니다. Equations & Guide에는 수식 이미지와 계수 설명이 있습니다. 모델 및 결과 엑셀의 Year Search와 Year Selection 시트에 실적함 적합도와 선택 근거를 보존합니다. 검증 예측 시트는 새로 생성하지 않습니다. 이전 모델을 재사용하지 말고 전체 실적함 자료로 다시 학습하세요.

## 개발

이 폴더에서 requirements.txt를 설치하고 `python -m unittest discover -s tests -v`를 실행합니다. Windows 빌드:

```
python -m PyInstaller --onefile --windowed --name SWBS_Regression --add-data "assets;assets" app.py
```

수식 PNG는 assets/equations에 포함되므로 실행 PC에 별도 렌더러가 필요하지 않습니다.
